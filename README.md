📚 Book Store Data Analysis | SQL Server

📌 Project Overview

This project focuses on analyzing a Book Store database using Microsoft SQL Server and SQL Server Management Studio (SSMS).

The objective is to analyze book sales, customer purchasing behavior, revenue, and inventory management using SQL queries to generate meaningful business insights.

🛠️ Tools & Technologies

* Microsoft SQL Server
* SQL Server Management Studio (SSMS)
* SQL

📂 Database Tables

* Books
* Customers
* Orders

📊 SQL Analysis

1. Retrieve all books in the Fiction genre
2. Find books published after 1950
3. List customers from Canada
4. Show orders placed in November 2023
5. Retrieve total available book stock
6. Find the most expensive book
7. Show orders with a quantity greater than 1
8. Retrieve orders with a total amount exceeding $20
9. List available book genres
10. Find the book with the lowest stock
11. Calculate total revenue generated from orders
12. Calculate total books sold for each genre
13. Find the average price of Fantasy books
14. Identify customers who placed at least 2 orders
15. Find the most frequently ordered book
16. Retrieve the top 3 most expensive Fantasy books
17. Calculate total books sold by each author
18. Identify cities where customers spent over $30
19. Find the highest-spending customer
20. Calculate remaining stock after fulfilling orders
